# Chriz Easy BG (CEBG)

**Early Windows alpha — expect bugs.** A few-click installer for Chriz's curated
Baldur's Gate / Enhanced Edition Trilogy setup.

Visit [the collection page](https://bg.chrizfader.org/collection) for the quick
start guide, contents, roadmap and download. Signed installer packages and their
checksums are published under [Releases](https://github.com/Chrizhermann/chriz-easy-bg/releases).
Each release includes its tested scope and known limitations.

You need your own clean BG:EE + Siege of Dragonspear and BGII:EE installations.
The initial verified profiles are English Steam 2.7.3 on Windows. CEBG makes a
separate modded copy; it does not supply the games or redistribute third-party mods.

The recommended setup follows the stream's curated baseline plus the approved
changes described per release. Customize offers alternatives, but not every
combination is tested. Evandra temporarily needs one official manual download,
or can be skipped before installation.

App updates are signed and deliver newer bundled setup recipes. Updating CEBG does
not change an existing game or save; a new setup is installed separately. Safe
in-place game hot-patching is not included in the first alpha.

This repository hosts public distributions, update metadata and player-facing
information. Mod credit belongs to the original authors; source and project links
are retained in the recipe. Please report problems with the CEBG version and logs,
after checking logs for personal paths or other information you do not wish to share.

The updater signature is not a Windows Authenticode publisher certificate. The
installer may show an unknown-publisher warning. Obtain downloads only from the
official page or this repository, and compare the published SHA-256 checksum.
