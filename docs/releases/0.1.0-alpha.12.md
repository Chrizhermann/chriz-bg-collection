# Chriz Easy BG 0.1.0-alpha.12 — Windows alpha

Small installer hotfix: CEBG now creates missing installation folders, including a
missing `Games` parent folder. You do not need to create them manually first.

Enter the full new folder path in **Install location**, or use **Browse…**. The page
explains that missing folders will be created when installation starts. Changing a
rejected location remains possible. Existing nonempty folders, source-game/cache
overlap and unsafe links remain protected; this is not permission to overwrite files.

The bundled recipe stays at **0.1.0-alpha.12**, with the same 434 recommended
components and corrected SoD Remix v0.6.8. This is an application-only hotfix:
existing game installations and saves are unchanged.

Use Updates in CEBG or download this installer. Windows may show an unknown-publisher
warning: this setup is signed for CEBG's updater, not Windows Authenticode-signed.

## Still alpha

Clean supported English Steam BG:EE + SoD and BGII:EE 2.7.3 sources are required.
If Evandra is selected, choose her official Windows download when prompted, or skip
her. Downloads/mod installation take time; keep the computer awake.

This hotfix does not automatically repair older failed installations. Keep a failed
folder unchanged and export diagnostics for support. In particular, a prior SoD 900
failure needs a targeted recovery assessment, not a blind reinstall into that folder.

The missing-parent fix has synthetic filesystem and application-flow coverage. No
additional full mod installation or native-window interaction is claimed for this
small patch. See the [alpha.11 guide and release notes](https://github.com/Chrizhermann/chriz-easy-bg/releases/tag/v0.1.0-alpha.11)
for the complete installation guide, credits and alpha boundaries.
