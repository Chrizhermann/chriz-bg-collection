# Chriz Easy BG 0.1.0-alpha.11 — Windows alpha

An early public alpha of Chriz's curated Baldur's Gate setup. Expect bugs and
machine-specific problems; please report them with the CEBG version and a diagnostic
ZIP after reviewing it for paths or logs you do not want to share.

## What's new

- Fixes the SoD Remix treasure-chest installation failure that could stop the setup
  before later mods, including BuffBot. The recipe now uses SoD Remix v0.6.8 and
  preserves existing chest contents. The selected component list is unchanged.
- Customize now keeps the mod source and choice-group context visible across all 26
  categories. Thirty-three mutually exclusive groups use compact selectors, including
  a clear None / unchanged option, while preserving dependency and conflict checks.
- My installs now shows a searchable list of recorded/current WeiDU components, reported
  versions, and missing or extra rows. It does not claim resource-byte or in-game checks.
- Known managed installs with a terminal receipt can export diagnostics locally.
  Diagnostic ZIPs begin with a readable outcome, version, and run-evidence summary while
  retaining the underlying evidence for support.
- Completion and My installs include concise first-play tips for the game, BuffBot, and
  the optional BG Radar Overlay when applicable.

- If automatic resume is unsupported, the installer now asks you to preserve the
  folder and export diagnostics rather than declaring the whole copy irreparable.
- Exported JSON diagnostics stay valid JSON after private download URLs are redacted.

## Start here

1. Install clean, unmodded BG:EE with Siege of Dragonspear and BGII:EE. This alpha
   targets the verified English Steam 2.7.3 game profiles on Windows. Other storefronts
   are not yet equivalently verified; do not bypass an unsupported-source warning.
2. Open CEBG, check the detected game sources and choose a separate installation
   folder with sufficient free space. Keep the recommended setup or use Customize.
3. If Evandra is selected, use her official download page, download the Windows
   `evandra-v2.2.exe`, then choose that file in CEBG. Do not run it yourself. CEBG
   verifies and unpacks it. Alternatively choose Skip Evandra.
4. Choose Install and keep the computer awake. Downloads and installation can take
   a long time. CEBG does not modify your clean source games.
5. When complete, use Play or Open game folder. A desktop shortcut is optional.

Use Pause after current mod for a planned break; wait until CEBG reports paused.
After interruption, reopen CEBG and use its offered Continue/Retry action. Do not
manually rerun WeiDU in a managed installation. If automatic resume is unavailable,
keep the installation folder unchanged and export diagnostics for support. A targeted
repair may be possible after the underlying problem is fixed; a full restart is not
automatically necessary. This release does not yet provide automatic targeted repair.

## Included in this alpha

- The curated EET setup behind Chriz's stream playthrough, with approved new recipe
  changes in bundled recipe `0.1.0-alpha.12`. It is not a byte-identical copy of an
  existing stream installation or save.
- Optional customization, recorded install versions/component receipts and BG Radar Overlay.
- Separate app/setup update information. App updates deliver newer bundled recipes;
  existing game folders and saves stay unchanged. A new setup creates a separate install.
- Upfront Evandra download-or-skip, Windows archive verification and safe unpacking.
- SoD Remix, including the optional in-game SoD skip prompt and 250,000 XP for the
  protagonist on the skip route.
- Approved progressive utility XP and Yoshimo/Hexxat choices; Hexxat defaults to
  Shadowdancer. Alternatives remain mutually exclusive.

## Known alpha boundaries

The recovered full install has user-reported successful gameplay. The app's new
presentation, install inventory, diagnostic-export and summary paths have automated
coverage, but this exact app/recipe pair has not been replayed as another full install.
Native updater apply/restart and safe-pause app-close interaction still need broader
acceptance. Not every customized combination or imported-save variant is tested. Some
changes require a new playthrough; automatic game hot-patching is not included.

An empty BuffBot `attempts` list means there is no finalized BuffBot run record in that
receipt. It does not prove WeiDU never started. Check the raw evidence and later resume
history. A crash before the first terminal receipt can still prevent diagnostic export;
preserve the install folder and its `.chriz` evidence.

The installer is updater-signed, not Windows Authenticode-signed. Windows may show
an unknown-publisher warning. Download only through the official collection page or
release repository; the release includes a SHA-256 checksum. Antivirus checks are
useful but are not a guarantee of safety.

All mod credit belongs to the respective authors. CEBG distributes the recipe and
installer, not third-party mod archives. Project and source links remain available in
the recipe and public component inventory.
