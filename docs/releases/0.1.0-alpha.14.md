# Chriz Easy BG 0.1.0-alpha.14 — Windows alpha

- **Keep installation progress:** recover checks that stopped a mod before WeiDU
  started, instead of incorrectly requiring a new game copy. Recovery verifies the
  saved attempt evidence and keeps already-completed mods. Ambiguous failures after
  WeiDU started still require their normal recovery checks.
- **Windows process detection:** a process proven to have exited no longer blocks
  installation merely because Windows can still report its executable path. Live
  processes in the installation folder remain protected.
- **Remember setup choices:** unfinished customization, paths and naming survive
  restarting CEBG. Sources and destinations are checked again before installation.
- **Distinct game shortcuts:** Play shortcuts no longer collide with CEBG's own
  app shortcut. Existing unrelated shortcuts are preserved; shortcut failure does
  not turn a completed game installation into a failure.
- **Useful errors:** folder and installation failures show their native technical
  detail, making permission and path problems easier to identify.

The collection remains **0.1.0-alpha.12**, with the same 434 recommended components
and unchanged mod versions. This update does not modify completed games or saves.

## Continuing an interrupted installation

Update CEBG, open **My installs**, and use the offered resume/retry action. CEBG
checks the existing copy; it does not silently restart or change its frozen recipe.
If it still reports that recovery is unsafe, retain the diagnostics and ask for
help rather than deleting files or installing over the folder manually.

Clean supported English Steam BG:EE + SoD and BGII:EE 2.7.3 sources are required
for a new installation. If Evandra is selected, supply her official Windows
download or skip her. Keep the computer awake during installation.

This is alpha software. The package is signed for CEBG's updater, not Windows
Authenticode-signed; an unknown-publisher warning may still appear.
