# Chriz Easy BG 0.1.0-alpha.13 — Windows alpha

Two installation fixes from community reports:

- **EET and Windows paths containing spaces:** corrects the pinned EET installer's
  Documents-folder lookup. It no longer cuts the path at its first space and then
  fails while creating the EET settings/save folder or `Baldur.lua`.
- **Misleading inactivity warning:** quiet mod installation now gets five minutes
  before a notice, instead of 30 seconds. New output clears the notice automatically.
  The notice explains that installation is still running; its button is **Keep waiting**.

The bundled recipe remains **0.1.0-alpha.12**, with the same 434 recommended components,
SoD Remix **0.6.8** and BuffBot at the end. No curation selections or source versions
have changed. CEBG applies a narrowly checked compatibility correction to its staged
EET installer, not to the original download or your source games.

## If an earlier attempt failed

Update CEBG first. For a fresh attempt, choose a **new empty installation folder**;
do not install over the failed copy. Starting fresh uses the current bundled recipe,
including the earlier SoD component 900 fix. No manual EET edit is needed.

Existing retryable EET attempts can receive the path correction, but resuming keeps
their original frozen recipe. In particular, an older plan containing SoD Remix 0.6.7
does not become 0.6.8 merely because CEBG was updated. Keep old failure evidence if
you need support; the app does not silently rewrite recipes or force unsafe recovery.

## Still alpha

Clean supported English Steam BG:EE + SoD and BGII:EE 2.7.3 sources are required.
If Evandra is selected, supply her official Windows download or skip her.
Keep the computer awake during installation. Updates do not modify an existing
completed game or its saves.

Windows may show an unknown-publisher warning: the package is signed for CEBG's
updater, not Windows Authenticode-signed. Focused installer/Windows-path and app-flow
tests cover this patch; a new full-stack game installation is not claimed.
