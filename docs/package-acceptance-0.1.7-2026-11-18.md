# 0.1.7 package verification — November 18

App **0.1.7** bundles collection **0.1.4**. The build used `main` at
`62f4ab7bb3f7e64f86d15d3d3d48b3b699b4622f`, the merge of PR #153. The PR head was
`1f1d8c369352f117b65fcc598aed738069ba2957`. [Release preparation PR #153](https://github.com/Chrizhermann/chriz-bg-collection/pull/153)

## What this release changes

- **BuffBot v1.16.2** updates the Italian catalog. [PR #149](https://github.com/Chrizhermann/chriz-bg-collection/pull/149)
- **The Artisan's Kitpack v4.81a-dev.85928f9-chriz.7** and **Bardic Wonders v2.9c-balance.9**
  fix projectile behavior that could block saving or resting while passive abilities, songs,
  Inspirations or kit auras were active. [PR #151](https://github.com/Chrizhermann/chriz-bg-collection/pull/151)
- **BG Rebalance v0.8.12** adds Round Clock (component **361**). It counts travel, rest and
  scripted time advances toward cooldowns and Contingency checks. It is enabled by default
  with EEex under **Spells → Spell balance** in **Customize**. [PR #152](https://github.com/Chrizhermann/chriz-bg-collection/pull/152)
- **Collection 0.1.4** advances from **0.1.3** in app 0.1.6. Chris's Recommended contains
  **468 default components, 70 runs and 56 mods**. [Release notes](release-notes-0.1.7.md)
