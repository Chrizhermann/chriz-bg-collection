# Chriz Easy BG 0.1.0-alpha.18 — draft

Not published. Collection **0.1.0-alpha.16**; recommended selection remains
**448 components / 50 mod-install runs**.

## Installer improvements

- WeiDU runs in the background without opening console windows over other apps.
- Downloads automatically retry temporary network failures.
- Technical logs expand reliably during installation; Customize categories can
  be collapsed independently and have clearer, framed headings.
- Improved progress-view sizing avoids unnecessary scrolling when content fits.
- Failed and completed managed installations can be removed with explicit folder
  confirmation. Missing folders can be removed from the list without deleting files.
- A visible loading screen appears while CEBG searches for your games.

## Collection updates

- **Modpack v0.2.0-alpha.7:** fixes installation failures affecting Mazzy, Xan and
  Yeslick/Keldorn's Dispel Magic when other mods changed valid incoming data.
  Related companion builds handle proficiency changes more consistently while
  preserving unrelated effects. Existing component choices remain unchanged.
- **SoD Remix v0.6.11:** fixes Skie recruitment installation alongside Khalid's
  continuity changes; includes the accepted bridge, companion and SoD-skip work.
- Updated Artisan's Kitpack, Bardic Wonders, Spell Revisions, BG Rebalance and
  BuffBot releases from the expanded candidate are retained.
- Includes companion continuity, BG1 Yeslick's selected kit, Spellhold Imoen XP
  catch-up and official Safana with arrival inventory cleanup.
- Classic bouncing Lightning Bolt is the default SR choice; the non-bouncing
  alternative remains available. Includes SR/Rogue Rebalancing compatibility.
- Restores Edwin's optional Red Wizard default and enables the optional racial
  kit unlock by default. Armor-thieving QoL remains default-checked.
- More optional SCS and Tweaks Anthology choices, with enforced alternatives and
  compatibility notes. The three SCS immersion options are unchecked and marked
  not recommended/experimental. Dragon challenge choices remain unchecked.
- The Murder of Acton Balthis is now unchecked by default.

## Existing games

Updating CEBG updates the installer and launcher. The new collection applies to
new installations; this release does not patch existing games or saved companions.
There is no need to rebuild a working playthrough solely to update the app.

Review and installer tests are complete for the new Modpack release; its native
gameplay remains untested. This is still an alpha, not a guarantee that every
optional combination has been playtested.

Packaging and public publication are pending. See the
[candidate record](alpha18-candidate-2026-09-20.md) for exact evidence and boundaries.
