# Chriz Easy IWD 0.1.17

App **0.1.17** bundles collection **0.1.18**. Chris's Recommended includes **147 default
components across 35 install runs and 34 mods**, with **18 recruitable companions**.

## Highlights

- **No more crash after the multiplayer lobby.** Chriz Multiplayer Fix **v0.1.0** stops the
  random crash right after leaving Beamdog's multiplayer lobby, for example on
  **Multiplayer → Local network game → Load**.
- **Copy saves between single player and multiplayer.** On the Load screen, click **Copy**
  in a save's row. The copy lands in the other mode's save list and the original save
  stays. Viewers can build the party together in multiplayer for a chatter run, and you
  play on in single player.
- **Both reach games you already installed.** The multiplayer fix and the copy button come
  as a hotpatch and work in a game in progress. New installations include them by default.
- **Chriz IWD Encounters v0.3.2 for new games.** Mixed elite squads with real multiclasses
  in Chapters 2–6, Kaylessa as a level-15 elven weapons master, fewer kills needed for the
  related quests, and an endless staircase respawn fixed. In the finale, Poquelin's
  transformation dispels the party again as in the base game. The optional Heart of Winter
  and Trials of the Luremaster overhaul repairs the Polar Bear Spirit's roar, thins Burial
  Isle's undead and puts a Frost Giant War-Shaman with two Frost Giant Jarls on the glacier
  in Gloomfrost. A game in progress keeps its existing encounters.

## Installing and updating

- On app **0.1.7–0.1.16**, choose **Updates → Update Chriz Easy IWD app**.
- On **0.1.1–0.1.6** or for a first-time setup, download and run
  [Chriz.Easy.IWD_0.1.17_x64-setup.exe](https://github.com/Chrizhermann/chriz-easy-iwd/releases/download/v0.1.17/Chriz.Easy.IWD_0.1.17_x64-setup.exe)
  from the [v0.1.17 release page](https://github.com/Chrizhermann/chriz-easy-iwd/releases/tag/v0.1.17).
- For an existing game, update the app, close the game, then open **Updates** and choose
  **Check for a hotpatch** and **Apply hotpatch**.
- Updating the app leaves existing games unchanged otherwise; choose **New installation**
  for the collection **0.1.18** setup with Encounters v0.3.2.

Tested with Icewind Dale: Enhanced Edition 2.7.3.0 on 64-bit Windows 10 or 11 (about 8 GB
of free space); other usable Windows copies install as Less tested.
