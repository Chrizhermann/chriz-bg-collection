# Chriz Easy IWD 0.1.11

**Kuldahar dark stone, riveted timber & glacial cyan interface — plus Feedback, flexible source
detection, and exFAT/FAT32 support.** App **0.1.11** (bundled collection **0.1.10**, 30 mods
with 140 components and 18 companions) brings the classic Icewind Dale look and the latest
shared installer improvements to Chriz Easy IWD. Updating the app leaves installed games and
saves unchanged.

## Highlights

- **Classic Icewind Dale aesthetic & typography.** Replaces the light interface with dark
  cracked slate stone, riveted stained oak timber headers and buttons, glowing glacial cyan
  primary plaques, a carved Kuldahar diamond crest and icon, dark NSIS setup artwork, and
  bundled multi-weight `Spectral` and `Alegreya Sans` fonts.
- **Cleaner Install, Customize, My installs & Updates.** Single-source detection uses the full
  card width with an aligned **Browse…** button, **Customize** adds a sticky left-hand chapter
  index beside a single-column mod list, **My installs** puts **Play Chriz Easy IWD** at the
  top of a dedicated launch header, and **Updates** spans the full window width with **Check
  all for this game**.
- **Feedback and problem reports from the app.** Use **Feedback** in the header or **Report a
  problem** on a stopped or partial installation to preview a prefilled report, open it on
  GitHub or copy it for `#mod-feedback` on Discord. Diagnostics bundles redact your Windows
  user name and computer name and can be exported before an attempt finishes.
- **exFAT/FAT32 installation drives & flexible game detection.** Installing onto exFAT or
  FAT32 drives no longer stops with `os error 1` on hard links, and source detection accepts
  renamed executables and older `.bif` layouts cleanly while staging a verified `icewind.exe`
  copy inside the managed game folder.

On app **0.1.7** to **0.1.10**, use **Updates → Update Chriz Easy IWD app**. On
**0.1.1–0.1.6**, install `Chriz.Easy.IWD_0.1.11_x64-setup.exe` by hand once.

Windows 10 or 11 (64-bit), Icewind Dale: Enhanced Edition 2.7.3.0 and about 8 GB of free
space are required. Keep the computer awake during installation.
