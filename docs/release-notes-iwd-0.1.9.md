# Chriz Easy IWD 0.1.9

**Fewer stops during installation.** Chriz Easy IWD now comes from the same code as Chriz
Easy BG and gets its installer improvements. When a mod's download has changed since we
reviewed it, the installer installs the newer file; when a download cannot be used at all,
it leaves that mod out together with the mods that need it. The end of the installation
names both. If a mod's installer fails, the installer asks whether to leave out what did not
install and continue, try again where that is safe, or stop. A game that looks modded
already gets one question before anything is copied.
Steam's Icewind Dale: Enhanced Edition 2.7.3.0 in English stays the tested setup; other
usable Windows copies install as **Less tested**, and their details say how they differ.

**What the game files hold no longer stops an install.** Our own mods write the result we
decided, whatever another mod or a hand edit left in the game files before.

**New installations use the newest BuffBot and Chriz IWD Encounters.**
- **BuffBot 1.16.1** (was 1.12.6): the party table shows one row per buff with the party as
  columns, sets the cast order, plans a clone before you have it, and lets summons receive
  buffs. A game already in progress can get it through **Updates → Update BuffBot**.
- **Chriz IWD Encounters 0.2.2**: every boss fight is written as decided, whatever the game
  files hold; the Idol always gets its three spells. Games in progress keep the fights they
  have. No new hotpatch is included.

The recommended setup stays at **29 mods with 139 components** and **18 companions**.

On app **0.1.7** or **0.1.8**, use **Updates → Update Chriz Easy IWD app**. On
**0.1.1–0.1.6**, install the new setup by hand once. Updating the app leaves installed
games and saves unchanged.

Windows 10 or 11 (64-bit), Icewind Dale: Enhanced Edition 2.7.3.0 and about 8 GB of free
space are required. Keep the computer awake during installation. This remains an early
release: a full lab installation of the recommended setup (139 of 139 components) started
the game and loaded a save on 2026-11-08, but the changed fights have not been played.
