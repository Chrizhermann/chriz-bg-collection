# Chriz Easy IWD 0.1.9 (draft)

**New installations use the newest BuffBot and Chriz IWD Encounters.** BuffBot's party
table can show one row per buff with the party as columns, set a cast order, plan a clone
before it exists, and let summons receive buffs. Its 5E spell rows remain visible when a
hand-edited wrapper cannot name a usable target. A game already in progress can receive the
BuffBot release through **Updates → Update BuffBot**.

**Chriz IWD Encounters writes every selected boss fight as decided.** Edited values, missing
placements and occupied script slots no longer stop, warn or skip a fight; the Idol always
receives its three spells. Existing games retain the fights they already have.

The recommended setup remains **29 mods with 139 components** and **18 companions**. New
installations pin BuffBot 1.16.1 and Chriz IWD Encounters 0.2.2. No new hotpatch is included.

Updating the app leaves installed games and saves unchanged. Windows 10 or 11 (64-bit), a
clean Icewind Dale: Enhanced Edition 2.7.3.0 and about 8 GB of free space are required. This
is an early release: the IWD Encounters v0.2.2 lab installed all 139 recommended components
and started the game, but the changed fights have not been played.
