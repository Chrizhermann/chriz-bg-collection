# Chriz Easy IWD 0.1.10 (draft)

**Thieves use their skills in any armor.** Klatu Tweaks and Fixes lets thieves use their
thieving skills and stealth in any armor, without added skill penalties, as in Chriz Easy BG.
Equipment permissions and spellcasting restrictions stay as they are. It is on in the
recommended setup and can be switched off under Quality of life in Customize.

The recommended setup now has **30 mods with 140 components** and **18 companions**. New
installations get the change; a game in progress keeps its armor rules.

On app **0.1.7** to **0.1.9**, use **Updates → Update Chriz Easy IWD app**. On
**0.1.1–0.1.6**, install the new setup by hand once. Updating the app leaves installed
games and saves unchanged.
