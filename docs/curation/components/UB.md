## UI/dependency notes

- All offered BG2 Unfinished Business components are optional and unchecked by
  default at Christopher's request (2026-10-16); keep them available for opt-in
  in Customize.
- Component `3` is deliberately excluded; maintained modpack component `600` removes its
  problematic Spellhold hunt behavior from reference installs, but a fresh stack should
  not install both.
- Component `19` and Ascension `40` are alternative providers of restored Bhaalspawn
  powers and must not both be generated. The canonical provider remains a curation
  decision.
- Components `13` and `14` are offered as optional choices even though the reference did
  not install them.
- v28 remains the latest release. Do not silently follow unreleased v29 work from
  `master`, and remove the unrelated Bubb's Spell Menu archive candidate from UB's source
  metadata.
