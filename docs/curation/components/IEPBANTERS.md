## UI/dependency notes

- Components `6`–`11` form one optional, mutually exclusive banter-interval group.
  Choosing none is valid; component `8` (20 minutes) is the default when the group is
  enabled.
- The interval group is unavailable if an accelerator from Banter Pack (`1`/`3`),
  BG1NPC (`25`/`100`), Kelsey (`2`), or Keto (`3`) is selected. None of those competing
  components is currently part of this collection.
