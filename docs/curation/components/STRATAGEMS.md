## Related collection layers

- `chriz-bg-rebalance` is the post-SCS collection layer for specific SCS/SR fixes and
  balance adjustments. Curate those components in its own catalog rather than folding
  them into SCS's decisions.
- `chriz-bg-script-engine` is a separate, SCS-inspired compatibility and scripting
  project. It is currently research/architecture only and contains no production runtime,
  so it is not yet an installable collection component or a replacement for these SCS
  selections.
