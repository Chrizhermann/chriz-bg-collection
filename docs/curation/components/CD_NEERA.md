## Integration note

A player voicepack: it adds a selectable soundset for player characters by appending one
`charsnd.2da` column, its `M_cdsnd.lua` menu name and its sound files; it changes no NPC,
item or spell. It requires the EE 2.6 soundset layout (99 `charsnd.2da` rows) and installs
on BG:EE, SoD, BG2:EE and EET. The collection installs only `cd_neera/` with its pinned
WeiDU, never the bundled `setup-cd_neera.exe`, in its own run after EET_end and before
BuffBot. Christopher's decision (2026-10-22): every voicepack is a default under
"Voicepacks".

The reference install contained an older local build; this catalog lists the published release.
