# Theme fonts

The app themes ship these heading fonts so the app looks the same offline. Both are licensed
under the SIL Open Font License 1.1; each folder holds the font's copyright line and the full
licence text in `OFL.txt`. The fonts are unmodified WOFF2 subsets taken from the Fontsource
npm packages, which repackage the Google Fonts releases.
